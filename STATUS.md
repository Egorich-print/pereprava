### Критичные исправления (v0.6, аудит)

- write-back: повторный COMMIT больше не плодит дубликаты на телефоне;
  удаление «сохранённого» файла реально удаляет его с устройства;
  `create` по существующему имени не срезает файл в ноль.
- `write` больше не врёт про `stable_how` → данные не теряются без COMMIT.
- индекс тома при flush берётся у родителя (SD-карта ≠ internal).
- staged read не отдаёт нулевой хвост; запись в каталог → `NFS3ERR_ISDIR`.
- `watch` не крэшлупит при занятом порту (порт = singleton) и
  перемонтирует том, если тот пропал; `test_session` ограничен таймаутом.
- actor: кандидаты без storages отвергаются; тикер прогресса не течёт;
  `force_close` снимает зависший актор.
- mount/unmount: корректное экранирование путей, один запрос пароля.
- `pull_tree`: защита от path traversal в именах с устройства.

### Нужен один sudo (финальный шаг)

Демон под root всё ещё крутит старый бинарь (от 4 сентября) и держит
устройство. Чтобы подхватить новый код:

```shell
sudo launchctl kickstart -k system/com.egorich.pereprava
# или полная переустановка:
scripts/install-autorun.sh
```
